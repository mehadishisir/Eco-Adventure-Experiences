# Eco Adventure Experience 🌿

A responsive React web app for exploring and booking eco-friendly adventures.
Built with React, Firebase Authentication, and Tailwind CSS.

🔗 Live Demo: https://eco-adventure-experience-d8e4a.web.app/

## Features

- Firebase Authentication (Login / Register)
- Private Routes
- Dynamic adventure details
- Responsive & mobile-friendly UI
- Dark/Light mode (DaisyUI)

## Tech Stack

- React, Vite
- Tailwind CSS, DaisyUI
- Firebase Authentication & Hosting

## Installation

git clone https://github.com/your-username/eco-adventure-experience.git  
cd eco-adventure-experience  
npm install  
npm run dev
